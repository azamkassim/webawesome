# NEXUS RM Form Shell

A local-only proof of concept showing how Web Awesome Free components can support a relationship manager site-visit workflow.

## Boundaries

- Uses only components included in the free repository.
- Loads scripts, styles, icons, and fonts from the locally built Web Awesome site.
- Applies a restrictive Content Security Policy with network connections disabled.
- Does not submit, upload, persist, score, approve, or create canonical records.
- Requires fictional or redacted information during evaluation.

## Run locally

From `packages/webawesome`, run `npm run build:serve`, then open:

`http://localhost:4000/assets/examples/nexus-rm-form-shell/`
